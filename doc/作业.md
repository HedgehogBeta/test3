### 题目 2：位运算封包（含校验和）

补全 `command_pack_create(pkt, cmd_high, cmd_low)`，用移位和按位或填入：

- `header[0]`、`header[1]` 填入 `0xA5`
- `cmd[0]` 填入 `cmd_high`，`cmd[1]` 填入 `cmd_low`
- `checksum` = `header[0] + header[1] + cmd[0] + cmd[1]` 的低 8 位

```c
command_packet pkt;
command_pack_create(&pkt, 0x03, LED1_PIN);
// pkt = {0xA5, 0xA5, 0x03, LED1_PIN, 校验和}
```

要求：

1. 必须用位运算完成，不得逐字节赋值成员；
2. `HEADER_BYTE` 和 `PACKET_CHECKSUM` 宏已定义在头文件中。

### 题目 3：位运算解包（含校验）

补全 `command_pack_unpack(pkt, cmd_high, cmd_low)`，从协议包中解出命令并校验：

1. **包头校验**：用位运算将两个 `header` 字节拼成 `uint16_t`，与 `0xA5A5` 比较；
2. **校验和校验**：用 `PACKET_CHECKSUM` 宏重新计算，与 `pkt->checksum` 比较；
3. 两项校验均通过则将 `cmd_high`、`cmd_low` 写入输出参数并返回 `true`；任意一项失败返回 `false`。

`main.c` 中的调用流程已写好：

```c
// USER CODE 2：初始化队列，封包入队
packet_queue_init(&cmd_queue);
command_packet test_pkt;
command_pack_create(&test_pkt, 0x03, LED1_PIN);
packet_queue_push(&cmd_queue, &test_pkt);

// 主循环：出队 -> 解包 -> LED 执行
command_packet recv_pkt;
uint8_t cmd_high, cmd_low;
if (packet_queue_pop(&cmd_queue, &recv_pkt))
{
    if (command_pack_unpack(&recv_pkt, &cmd_high, &cmd_low))
    {
        command_led_execute(cmd_high, cmd_low);  // 已封装
    }
}
```

可自行修改 `USER CODE 2` 中 `command_pack_create` 的参数来测试不同的闪烁效果。

### 题目 5：用函数指针表封装状态机（选做）

在 `user/` 目录下新建文件，用函数指针表实现一个通用的有限状态机框架。

参考思路：

```c
typedef void (*state_func)(void);

static const state_func state_table[] = {
    [STATE_IDLE]    = state_idle_run,
    [STATE_RUNNING] = state_running_run,
    [STATE_ALARM]   = state_alarm_run,
    [STATE_COUNT]   = NULL            // 哨兵
};
```

要求：

1. 用枚举定义至少 3 个状态，每个状态对应一个运行函数；
2. 状态切换在运行函数内部完成（修改一个全局状态变量）；
3. 主循环只做一件事：查表 -> 调函数，不写 `switch`；
4. 用 LED 的不同闪烁模式体现不同状态（如待机=全灭、运行=流水灯、报警=快闪）；
5. 将文件加入 Keil 工程，编译下载确认现象。

提示：参考 README 中"函数指针与命令表"一节的思想，把"命令码 → 处理函数"换成"状态 → 运行函数"即可。
