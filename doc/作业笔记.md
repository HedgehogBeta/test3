# 嵌入式 C 培训笔记（8.10 作业）

## 一、题目 1：环形队列实现

### 实现要点

- FIFO 缓冲，解耦「产生命令的中断」和「处理命令的主循环」。
- `head`=下一个读的位置，`tail`=下一个写的位置，`(tail+1) % PACKET_QUEUE_SIZE` 取模回绕。
- `count` 区分空/满：`==0` 空，`==PACKET_QUEUE_SIZE` 满。
- 元素是 `command_packet` 结构体，直接整体赋值：`q->buf[q->tail] = *pkt;`。
- push 先判满、pop 先判空，顺序不能反。

### 关键代码位置

`common/src/command_pack_queue.c` 中 init / is_empty / is_full / push / pop 五个函数。

## 二、题目 2：位运算封包

### 实现要点

- 两个相邻字节 = 一个 16 位整数，**高字节在前 = 大端字节序**。
- 拼字：`((uint16_t)x << 8) | y`；拆字：`>> 8` 取高字节，`(uint8_t)` 强转截断取低字节。
- 拼拆字节序必须一致，否则解包对不上。
- 校验和 = `PACKET_CHECKSUM(header[0], header[1], cmd[0], cmd[1])`，即四字节相加的低 8 位。

### 关键代码位置

`command_pack_create`（command_pack_queue.c）

## 三、知识点

- **结构体**：相关变量打包成一个类型；同类型结构体可 `=` 整体赋值。
- **指针**：`q->head` 即 `(*q).head`；`const` 指针 = 只读契约。
- **输出参数**：函数要改调用方变量就传地址，函数里 `*pkt = ...` 写回；漏写 `*` 是常见坑。
- **环形队列**：取模回绕避免搬数据；满时策略=丢弃返回 false。
- **位运算**：`<<` `>>` `&` `|` `~` `^`；位运算用无符号类型；判断某位要加括号 `(flags & BIT) != 0U`；多字节字段拼拆用移位+强转。

## 四、调试记录

### 拼写错误：`packet_quene_is_full` → `packet_queue_is_full`

`quene` 应为 `queue`。`declared implicitly` + `Undefined symbol` 同时出现 = 调用的函数名和定义对不上，先怀疑拼写，对照头文件逐字母核对。

### 灯不亮：pop 和 unpack 的 3 个逻辑 bug

1. `pop` 赋值方向反了：`q->buf[q->head] = *pkt;` 应为 `*pkt = q->buf[q->head];`（输出参数是"往外写"）。
2. `pop` 返回了 `false`：应为 `return true;`，否则 main 的 `if(pop)` 整块跳过，这是灯不亮最直接原因。
3. `unpack` 校验通过后没写输出参数：需在 `return true;` 前加 `*cmd_high = pkt->cmd[0]; *cmd_low = pkt->cmd[1];`。

**教训**：能编译 ≠ 逻辑正确。现象不对时从结果倒推链路：执行→pop 返回值→unpack 校验→输出参数，逐级排查。
